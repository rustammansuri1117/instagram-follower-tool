# Instagram Growth Platform

Order-management web application for Instagram follower growth plans: featuring public plans, order checkout, order tracking pages, and a secure admin management portal.

## Quick Links
- **[Deploy to Render Guide](DEPLOY_TO_RENDER.md)**: 1-click Render blueprint and deployment setup.
- **[Application Code & Local Setup](instagram-growth/)**: Source code, instructions for local development, and database configuration.

## Features
- **Public Storefront**: Browse follower plans, order with Instagram handle & mobile number.
- **Order Tracking**: Track order status (Pending, Processing, Completed, Cancelled) securely.
- **Admin Panel**: Manage plans, process orders, toggle active status, and view sales metrics.
- **Render Ready**: Includes `render.yaml`, `gunicorn`, PostgreSQL support, and automated initial admin seeding.
